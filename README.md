# Dead by Daylight в Roblox

Асимметричный хоррор 1 vs 4 в стиле Dead by Daylight: один игрок — **маньяк**, остальные — **выжившие**.
Карта генерируется кодом заново каждый раунд, вручную в Studio ничего строить не нужно.

## Как запустить

### Вариант 1 — готовый файл (проще всего)
1. Скачай `DeadByDaylight.rbxlx` из этого репозитория.
2. Открой его в **Roblox Studio** (File → Open from File).
3. Для теста одному нажми **Play** — ты будешь выжившим (маньяка не будет).
4. Для настоящего теста: вкладка **Test → Clients and Servers**, выбери **2–5 игроков** и нажми **Start**.
5. Чтобы опубликовать: File → Publish to Roblox.

### Вариант 2 — через Rojo (для разработки)
```
rojo serve
```
и подключись плагином Rojo в Studio. Или собери файл: `rojo build -o DeadByDaylight.rbxlx`.

## Механики

**Выжившие**
- Чинят генераторы (держать **E**). Во время ремонта появляются **проверки навыка** — жми **Пробел**, когда стрелка в белой зоне. Провал — генератор теряет прогресс, а маньяк слышит шум.
- **Shift** — бег. Здоров → ранен → повержен (2 удара).
- Опускают **паллеты** (Пробел) — если маньяк рядом, он оглушается. Через опущенные паллеты и окна можно **перепрыгивать** (Пробел).
- Лечат и поднимают друг друга, снимают товарищей с крюков (держать **E**).
- После починки 5 генераторов запитываются **ворота** — открыть рычаг (держать E) и убежать. После открытия ворот начинается **обрушение** (2 минуты).

**Маньяк**
- Вид от первого лица, быстрее выживших (115%). **ЛКМ** — удар с выпадом.
- Поднимает поверженных (**E**), несёт к крюку и вешает (**E**). Видит ауры генераторов, а когда несёт выжившего — ауры крюков.
- Ломает паллеты и повреждает генераторы (**E**), перелезает через окна (**Пробел**).

**Крюки:** 1-й крюк — стадия 1 (60 с), затем стадия 2 (60 с), затем жертва. 3-е повешение — сразу жертва.
Выживший в руках маньяка вырывается сам за 16 секунд.

Работает и на телефоне — кнопки действий появляются на экране.

## Настройка
Весь баланс (скорости, время ремонта, кол-во генераторов, таймеры крюков и т.д.) — в `src/shared/Config.lua`.
Чтобы добавить звук сердцебиения, вставь ID звука в `Config.HeartbeatSoundId`.

## Структура
```
src/shared/Config.lua        — настройки
src/shared/Remotes.lua       — сетевые события
src/server/Main.server.lua   — цикл лобби/раунда
src/server/Match.lua         — вся игровая логика
src/server/MapBuilder.lua    — генерация карты и лобби
src/client/Client.client.lua — управление, ауры, радиус ужаса
src/client/UI.lua            — интерфейс
```
