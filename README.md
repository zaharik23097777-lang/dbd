# Dead by Daylight в Roblox

Асимметричный хоррор 1 против 4 в стиле Dead by Daylight: один игрок — **маньяк**, остальные — **выжившие**.
Персонажи R6 с анимациями, 3 маньяка со способностями, шкафчики, люк, тотемы, сундуки с предметами,
очки крови и лобби у костра. Карта генерируется кодом заново каждый раунд — в Studio ничего строить не нужно.

## Как запустить

### Вариант 1 — готовый файл (проще всего)
1. Скачай `DeadByDaylight.rbxlx` из этого репозитория.
2. Открой его в **Roblox Studio** (File → Open from File).
3. Тест в одиночку: **Play** — ты будешь выжившим (маньяка не будет).
4. Настоящий тест: вкладка **Test → Clients and Servers**, выбери **2–5 игроков** → **Start**.
5. Публикация: File → Publish to Roblox. Чтобы сохранялись очки крови, включи
   *Game Settings → Security → Enable Studio Access to API Services*.

### Вариант 2 — через Rojo (для разработки)
```
rojo serve            # и подключись плагином Rojo в Studio
rojo build -o DeadByDaylight.rbxlx
```

## Управление

| | Выживший | Маньяк |
|---|---|---|
| Бег | Shift | — (всегда быстрее) |
| Присесть | Ctrl / C | — |
| Действие (держать) | **E** — чинить, лечить, снять с крюка, сундук, тотем, капкан, люк | **E** — поднять, повесить, сломать паллету, повредить генератор, обыскать шкафчик |
| Пробел | паллета, перелезть через окно/паллету, шкафчик, **проверка навыка** | перелезть через окно |
| Атака | — | ЛКМ |
| Предмет / способность | R | ПКМ или Q |

На телефоне появляются сенсорные кнопки. Маньяк играет от первого лица.

## Маньяки (выбор в лобби)
- **Траппер** — ставит медвежьи капканы (держать ПКМ). Пойманный выживший ранен и не может уйти,
  может пытаться вырваться (E) или его освобождают товарищи. Выжившие могут обезвреживать капканы.
- **Охотница** — держи ПКМ, чтобы замахнуться, отпусти — бросок топора по дуге. 5 топоров, пополнение в шкафчике.
  Вместо сердцебиения её выдаёт колыбельная (меньший радиус ужаса).
- **Призрак** — звонит в колокол и становится почти невидимым и быстрым, но не может бить.
  Проявившись, получает короткий рывок. Свет фонарика сбивает невидимость.

В лобби есть кнопка **«Хочу быть маньяком»** — маньяк выбирается среди желающих.

## Механики
- **Генераторы** (5 из 7) с круглыми **проверками навыка**. Провал — взрыв и шум для маньяка.
- **Здоровье**: здоров → ранен → повержен (ползает, истекает кровью 4 минуты). Товарищи лечат и поднимают.
- **Крюки**: две стадии по 60 с; на 2-й стадии появляются лапы **Сущности**; 3-е повешение — жертвоприношение.
- **Паллеты** оглушают маньяка, **окна** и опущенные паллеты можно перепрыгивать.
- **Шкафчики**: спрятаться от маньяка; маньяк может обыскать шкафчик и вытащить выжившего.
- **Тотемы**: один проклятый — **«Руина»** (генераторы сами откатываются), пока его не очистят.
- **Сундуки**: аптечка (лечить себя), ящик с инструментами (+50% к ремонту), фонарик (ослепить маньяка).
- **Следы**: бегущие выжившие оставляют красные царапины, раненые — кровь (видит только маньяк).
- **Вороны** взлетают, когда рядом пробегает выживший, и выдают его.
- **Погоня**, **радиус ужаса** (пульсирующая виньетка + сердцебиение), **красное пятно** перед маньяком.
- **Ворота** и **обрушение Сущности** (2 минуты), **люк** для последнего выжившего (маньяк может закрыть).
- **Очки крови** по категориям (Цели, Выживание, Альтруизм, Смелость / Жестокость, Коварство, Охота, Жертвоприношение).

## Анимации
Все анимации R6 **процедурные** — их считает код (`src/shared/Anim/Poses.lua`), загружать ничего не нужно:
ходьба/бег, хромота раненого, присед, ползание, перенос на плече, висение на крюке, ремонт, лечение,
перелезание, удар с замахом, оглушение, ослепление, бросок топора, колокол Призрака, сидение у костра и другие.
Персонажи всегда R6 — игра сама создаёт их из аватара игрока.

## Звук
По умолчанию используются **звуки, встроенные в клиент Roblox** — они гарантированно работают в любой игре.
Сердцебиение, взрывы генераторов, удары, колокол и т.д. собраны из них с помощью высоты тона и эффектов.
Чтобы поставить свои звуки, найди их в Studio (Toolbox → Audio) и впиши ID в `Config.SoundOverrides`
в `src/shared/Config.lua`:
```lua
Config.SoundOverrides = {
	Heartbeat = "rbxassetid://...",   -- сердцебиение
	ChaseMusic = "rbxassetid://...",  -- музыка погони
	Lullaby = "rbxassetid://...",     -- колыбельная Охотницы
	AmbientMusic = "rbxassetid://...",
	Scream = "rbxassetid://...",
}
```
Все имена звуков — в `src/shared/Sounds.lua`.

## Настройка
Весь баланс (скорости, время ремонта, таймеры крюков, предметы, радиусы) — в `src/shared/Config.lua`,
маньяки — в `src/shared/KillerDefs.lua`.

## Структура
```
src/shared/        Config, Remotes, KillerDefs, ItemDefs, ActionInfo, Sounds, Util
src/shared/Anim/   Rig (математика суставов R6), Poses (все позы)
src/server/Core/   State, Actions (реестр действий), Match, Characters (R6), Lifecycle, Scoring, Lobby
src/server/Systems Health, Carry (крюки), Combat, Generators, Exits (ворота/люк), Obstacles (паллеты/окна),
                   Lockers, Totems, Items, Crows, Chase
src/server/Powers/ Trapper, Huntress, Wraith
src/server/Map/    MapBuilder (карта, лобби, свет), Props (все объекты)
src/client/        Animator, CameraController, Audio, Effects, Auras, Interaction, Input, UI/*
tests/             проверки для Lune (карта, анимации, интерфейс)
```
